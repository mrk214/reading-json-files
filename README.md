## 🔑 Key files

Although this is a Vite project with several configuration and boilerplate files, only the following files are relevant to understanding the application:

- [`src/types.ts`](https://github.com/mrk214/reading-json-files/blob/main/src/types.ts) — TypeScript types for the JSON files
- [`src/App.tsx`](https://github.com/mrk214/reading-json-files/blob/main/src/App.tsx) — Main application component
- [`src/constants.ts`](https://github.com/mrk214/reading-json-files/blob/main/src/constants.ts) — Application constants
- [`src/dev.types.ts`](https://github.com/mrk214/reading-json-files/blob/main/src/dev.types.ts) — Development-only types specific to this implementation
